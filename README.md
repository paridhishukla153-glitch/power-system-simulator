# Power System Simulator

A modular Python-based power system simulator implementing core concepts of load flow analysis.

## Features

- Bus modeling
- Transmission line modeling
- Automatic Y-Bus matrix formation
- Active power calculation
- Reactive power calculation
- Mismatch vector calculation
- Jacobian matrix framework
- Network visualization using NetworkX
- IEEE benchmark system support
- CSV export of simulation results
